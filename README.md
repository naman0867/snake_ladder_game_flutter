# 🐍 Snake & Ladder Game (Flutter + Firebase)

## 📌 Project Overview
This project is a simple **Snake & Ladder game** developed using **Flutter** and **Firebase** as part of the *Emerging Technology* course mini-project.

The application includes:
- User authentication using Firebase
- A playable Snake & Ladder game
- A real-time leaderboard using Cloud Firestore
